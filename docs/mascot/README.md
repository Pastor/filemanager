# Сыч — маскот Janus

Janus — двухпанельный файловый менеджер для терминала. Назван в честь двуликого римского бога, который смотрит в обе стороны сразу.
Маскот — сыч с лицевым диском из двух «панелей»:

- **правый глаз открыт** и хитро прищурен — это активная панель;
- **левый глаз спит** («z z»), пока в фоне идёт копирование, поиск или подсчёт размеров;
- уши подыгрывают: левое опущено, правое торчит.

Характер — озорной: сыч всё видит, даже когда половина его спит.

## Файлы

```
svg/
  janus-owl.svg          персонаж в полный рост (240×240)
  janus-owl-scene.svg    сыч сидит на окне терминала — шапка README
  janus-owl-icon.svg     голова без тела — иконка и favicon (64×64)
png/
  janus-owl-256|512|1024.png        персонаж, прозрачный фон
  janus-owl-scene-1280.png          сцена, прозрачный фон
  janus-owl-scene-1280-paper.png    сцена на светлом фоне #f3f2f2
  janus-owl-icon-16|32|48|64.png    favicon
  janus-owl-icon-180.png            apple-touch-icon
  janus-owl-icon-192|512.png        PWA / аватар
```

## Как применять

- **README** — `janus-owl-scene.svg` в начале страницы, ширина 360–480 px.
- **Favicon** — 16 и 32 px берите только из `janus-owl-icon`: у полного персонажа мелкие детали пропадают.
- **Тёмный фон** — у силуэта тёмная обводка и светлые глаза, так что все варианты читаются и на светлом, и на тёмном фоне без отдельной версии.
- Отступ вокруг персонажа — не меньше ширины его глаза.
- Не перекрашивайте, не поворачивайте и не открывайте оба глаза сразу: открыт только правый.
